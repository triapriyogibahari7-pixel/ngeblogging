# Sidebar Comments collapse v116

Release: `sidebar-comments-collapse-v116-20260729`

- Pada desktop, laptop, komputer, perangkat besar, dan Desktop-site Android, sidebar tertutup hanya menampilkan ikon Komentar.
- Tulisan Komentar disembunyikan sepenuhnya tanpa mengubah posisi ikon.
- Saat sidebar dibuka, tulisan Komentar tampil kembali pada baris yang sama.
- Runtime lama tidak dapat memaksa label tampil kembali melalui inline `!important`.
- Perubahan kelas, resize, orientation, pageshow, dan redraw tombol disinkronkan ulang.
