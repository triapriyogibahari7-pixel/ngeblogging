# Editor capabilities

Editor Studio lanjutan menyediakan:

- pilihan model huruf dan ukuran huruf
- warna teks dan sorotan
- judul H1/H2, paragraf, bold, italic, underline
- perataan kiri, tengah, kanan, dan justify
- daftar, tautan, tabel, undo, redo, serta simpan
- unggah dan sisipkan gambar dari pustaka media
- pratinjau desktop dan mobile
- status draf/terbit dan slug konten
- konteks dokumen untuk Nara AI

Konten saat mode demo tetap disimpan di perangkat. Workspace login membaca profil dan situs dari Supabase; sinkronisasi penuh dokumen/revisi merupakan tahap berikutnya dari data layer.
